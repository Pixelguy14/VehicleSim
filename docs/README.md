# Documentación de VehicleSim

Este directorio es la memoria del proyecto: no solo describe cómo funciona el
código, sino por qué se tomó cada decisión y qué se aprendió en el camino.

## Convenciones

- Cada sprint tiene una página con: objetivo, alcance, decisiones tomadas,
  problemas encontrados, cómo se verificó y qué queda pendiente.
- Cada decisión técnica que no sea obvia se registra como ADR, incluso si al
  final se revierte: lo valioso es el razonamiento.
- La documentación se escribe al cerrar el sprint, no antes. Durante el sprint
  solo se mantiene actualizada la lista de sub-pasos.
